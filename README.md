# AES-CTR-in-CUDA-C
My final project for CS 4220. AES CTR parallel implementation using CUDA C

## Description
This project intends to implement a parallel version of AES-CTR using CUDA C, where it can encrypt / decrpyt text files, and images and then compare performance against a sequential CPU implementation.

## Features
- Can encrypt / decrpyt text files and images
- Comparison against CPU implementation (tiny-AES-c)
